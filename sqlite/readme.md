# things to know/remember about sqlite in rust

### [libSQL](https://github.com/tursodatabase/libsql/tree/main/libsql)

This project by Turso is for use with their web api.
I don't think that it is interchangable with a local sqlite db.


### [prsqlite](https://github.com/kawasin73/prsqlite)

This is a hobby project that is a pure rewrite of sqlite's repl in rust.
It does not work as a library to be added into your project.
